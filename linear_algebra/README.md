# Linear Algebra Practice

This folder contains my practical implementation of core linear algebra concepts using Python and NumPy as part of my Machine Learning foundation.

## Topics Covered

### 1. Vectors
- Vector addition and subtraction
- Scalar multiplication
- Dot product
- Vector magnitude
- Linear combinations

### 2. Matrices
- Matrix addition
- Element-wise multiplication
- Matrix multiplication
- Transpose
- Determinant

### 3. Linear Transformations
- Applying matrices to vectors
- Scaling transformations
- Shear transformations

### 4. Eigenvalues and Eigenvectors
- Finding eigenvalues and eigenvectors with NumPy
- Understanding eigenvectors as directions that remain unchanged under a transformation
- Understanding eigenvalues as scaling factors
- Verifying the relationship:

  `Av = λv`

### 5. Machine Learning Connection
Linear algebra is fundamental to machine learning. Matrix and vector operations are used in model predictions, transformations, optimization, and dimensionality reduction.

A simple linear model can be represented as:

`ŷ = Xw + b`
