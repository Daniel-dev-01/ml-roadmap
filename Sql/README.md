## Key Understanding

WHERE filters individual rows.

GROUP BY groups rows based on a column.

HAVING filters groups after aggregation.

ORDER BY sorts the result.

JOIN combines related data from different tables using a common column.

## Applied ML Connection

SQL is important in ML because real-world datasets are often stored in databases.

Before building a model, I may need to query, filter, aggregate, and combine data before loading it into Python/Pandas.
